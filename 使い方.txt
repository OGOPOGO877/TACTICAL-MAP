TACTICAL MAP  使い方（Windows）
================================

黒い画面が一瞬で消える人は、start.bat ではなく
「起動する.vbs」をダブルクリックしてください。
ウィンドウは閉じません。


0. いちばん大事なこと
----------------------
黒い画面（コマンド画面）は、アプリの本体です。
この画面を閉じると、マップも止まります。
起動中はずっと開いたままにしてください。


1. Node.js が入っているか
--------------------------
このPCには Node.js が入っている想定です。
入っていないと起動できません。

  1) Chrome で https://nodejs.org を開く
  2) 緑色の「LTS」をダウンロード
  3) インストーラーを開いて、ずっと「Next」→ Install
  4) 終わったらPCを再起動


2. アプリを起動する
-------------------
  1) デスクトップの TACTICAL-MAP フォルダを開く
  2) 「起動する.vbs」をダブルクリック
     （見つからなければ start.bat）
  3) 黒い画面が開いたままになる
  4) 初回だけパッケージのインストールで数分かかることがある
  5) Chrome が自動で開く
     開かないときは、Chrome の上の白い住所欄にこれを入力して Enter

        http://localhost:3000

  6) 「TACTICAL MAP」の画面が出れば成功


3. 2人以上で使う（同じPC / 同じ家）
-----------------------------------
通話しながら作戦を合わせるためのアプリです。

同じPCの2つの窓で試す:
  1) 起動したまま、Chrome をもう1つ開く
  2) 同じく http://localhost:3000 を開く
  3) 下の LOCAL DEV の ROOM を同じ文字にする
     例: raid1
  4) NAME は窓ごとに別でOK（同じにしない）
  5) 片方で PIN や PEN を書くと、もう片方に出る
  6) 上は CONNECTED のままが正常。RECONNECTING が点滅したら
     両方のChromeを F5 で再読み込みする

家族や友達のPCから使う:
  1) あなたのPCでアプリを起動したままにする
  2) 友達は Chrome であなたのPCのアドレスを開く
     例: http://192.168.0.12:3000/?room=raid1
  3) 数字の部分は環境で違います。わからなければ
     まずは同じPCの2窓で練習してください。


4. 画面の使い方
---------------
上:
  MAP     … タルコフのマップを選ぶ（CUSTOMS, WOODS など）
  CONNECTED と出ていれば通信OK
  RECONNECTING / DISCONNECTED なら黒い画面が閉じていることが多い

左のボタン:
  SELECT  矢印。マップを掴んで移動。置いたものを選ぶ
  PEN     線を描く。上に色と太さ（SIZE）が出る
          色の四角をタップ、SIZE を左右に動かす
  ARROW   ドラッグで矢印
  CIRCLE  ドラッグで円
  PIN     ピンを刺す（ENEMY TEAM DANGER LOOT EXIT MEET SNIPER）
  TEXT    地図をクリックして文字。Enter で確定
  ERASER  消す
  PING    「ここ！」と点滅。約3秒で消える
  UNDO    自分の最後の操作を取り消す
  REDO    取り消しをやり直す
  CLEAR   このマップの書き込みを全部消す（確認が出る）

地図:
  マウスホイール … 拡大縮小
  右クリックを押しながら移動 … 地図をずらす
  iPhone / iPad … 1本指で書く、2本指で拡大と移動
  FIT TO SCREEN … 画面に合わせる
  RESET VIEW … 表示を戻す

下:
  今つながっている人の名前


5. マップ画像が出ないとき
--------------------------
画像は最初入っていません。
「MAP IMAGE NOT FOUND」と出ても壊れではありません。

  1) TACTICAL-MAP の中の public フォルダを開く
  2) その中の maps フォルダを開く
  3) タルコフのマップPNGを、この名前で置く

     customs.png
     woods.png
     shoreline.png
     reserve.png
     interchange.png
     streets.png
     lighthouse.png
     ground-zero.png
     factory.png
     lab.png

  4) Chrome を再読み込み（F5）


6. うまくいかないとき
----------------------
黒い画面が一瞬で消える
  → 「起動する.vbs」を使う。それでもダメなら
     TACTICAL-MAP の中の start-log.txt を開いて中身を見る

Chrome に「接続できない」と出る
  → 黒い画面が開いているか確認
  → 住所は http://localhost:3000 （https ではない）

片方にしか書けない
  → 下の LOCAL DEV で ROOM が同じか確認

Discord で使いたい
  → まずはこのファイルの 1〜4 で
     「2つのChromeで同じ地図が動く」までやってください
  → そのあと README.md の Discord の手順へ進みます


7. 終了する
------------
黒い画面を閉じてOKです。
もう一度使うときは「起動する.vbs」からやり直します。
